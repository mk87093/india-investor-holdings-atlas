# India Investor Holdings Atlas

Make an application for NSE and BSE stocks which can show all FII and DII holding stocks, their percentage, and their position changes, structured and ranked by most holding percentage by FII. When clicking on a stock, show stock fundamental data and comparison with previous data: if any data is negative show in red box, if positive then show green box with data.
